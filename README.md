# 🥗 營養師系統 ｜ 熱量計算與菜單設計系統 (Nutrition Planner Desktop App)

專為營養師、長照機構及臨床飲食諮詢設計之單機版應用程式。根據臨床營養評估 EXCEL 工作表架構與衛福部六大類食物代換標準研發，具備左側現代化導覽列，操作清晰直觀。

---

## 🌟 核心特色與功能導覽

本系統依照標準臨床評估流程，透過左側導覽選單分為四大專題頁面：

### 1. ⚡ 熱量營養素計算
- **體態與指標評估**：個案姓名、性別、年齡、身高、體重、血清肌酸酐（Creatinine），即時連動計算 **BMI、理想體重 (IBW)、體重佔理想體重比 (IBW%)、正常體重範圍、eGFR 腎絲球過濾率與 CKD 臨床分期**。
- **三大營養素百分比試算表**：嚴格依照臨床計算公式（總熱量 × % ÷ 4或9 = 目標克數 g），支援一鍵套用【標準均衡 (50:20:30)】、【高蛋白健身 (40:30:30)】、【低蛋白腎病 (60:10:30)】。
- **BEE 基礎代謝率與 TDEE 每日熱量需求**：Harris-Benedict 公式搭配活動因子與臨床壓力因子（如手術、創傷、癌症、燒傷等）連動試算，可一鍵將 TDEE 套用為目標熱量。
- **臨床速算對照表**：提供 IBW (25/28/30/35 kcal/kg) 與 CBW (25/28/30/35/40/45 kcal/kg) 快速換算對照，點擊即可代入。
- **長照推算工具**：提供台灣長者 Chumlea 膝長公式、BAPEN MUST 尺骨長推算身高，以及臂圍 (MAC) 與臀圍推算體重功能。

### 2. 📖 食物代換表
- 完整內建衛福部六大類食物代換標準：全脂奶、低脂奶、脫脂奶、米食類、麵食類、豆魚蛋肉類（低/中/高脂）、蔬菜類、水果類、油脂類、堅果種子類與乳清蛋白。
- 顯示每單位標準份量說明，以及每份對應的蛋白質 (g)、脂肪 (g)、醣類 (g) 與熱量 (kcal)，支援自訂數值調整與一鍵恢復預設。

### 3. 🍱 菜單設計
- **六餐飲食份數分配**：提供【早餐、早點、午餐、午點、晚餐、晚點】各餐別份數規劃，亦可對照輸入個案之【實際份數】。
- **商業營養配方計算**：內建安素、健力體、倍力素、愛美力、雙卡、易能充、保惠壯等常見配方，直接規劃建議/實際份數。
- **即時小計**：自動即時結算天然食物與商業配方之熱量與三大營養素小計。

### 4. 📊 營養成分
- **全方位營養成分對照表**：橫向對照【目標規劃】、【建議菜單】與【目前實際飲食】之總熱量、三大營養素克數、熱量百分比與達成率差距。
- **營養師衛教建議**：可輸入飲食原則與生活指引。
- **本機 SQLite 個案歷史資料庫**：個案紀錄、歷史菜單與商業配方配置一鍵儲存、即時查詢載入與刪除管理。
- **衛教單一鍵匯出**：一鍵產生清新高質感的 HTML 衛教評估處方單，於瀏覽器中直接開啟，方便列印或儲存為 PDF。

## 🚀 執行說明

- **執行檔位置**：直接位於本資料夾根目錄下的 [`NutritionPlannerApp.exe`](./NutritionPlannerApp.exe)。
- **檔案大小**：已高度精簡至 **3.2 MB**，輕巧便於攜帶與放在 GitHub Release。
- **系統需求**：Windows 10 / 11（需安裝 .NET 8 桌面執行階段）。

## 🛠️ 技術架構
- **開發平台**：C# 12 / WPF (.NET 8.0)
- **資料庫**：SQLite (`Microsoft.Data.Sqlite`)
- **圖形架構**：左側深藍專用導覽列、卡片式格狀排版、即時資料綁定 (INotifyPropertyChanged)
